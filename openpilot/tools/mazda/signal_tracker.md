# Mazda 6 Wagon 2022 CAN 解析トラッカー

意味を調べている信号の管理表。機械的に出した全信号の一覧は [`unknown_signals.md`](unknown_signals.md)（`catalog.py` で再生成）で、ここには調べ始めたものだけを載せる。

- **状態**: ✅ 確定 / 🔶 仮説あり / ⬜ 未着手
- **根拠のルート**: 下の「参照したドライブ」の略称
- **DBC**: `opendbc/dbc/mazda_2017.dbc` での名前。（未登録）は DBC にまだ入れていないもの

## 参照したドライブ

| 略称 | ルート | 内容 |
|---|---|---|
| 186 | `389c201431bcc1b5/00000186--d4c2fba0c5` | 約 50 分。MRCC と VC モードで走行、レバー M とパドル操作あり。CTS なし |
| 18b | `389c201431bcc1b5/0000018b--91b661fef8` | 停車中と走行中に MRCC/CTS のアームと解除、SET+、CANCEL を操作 |

## ✅ 確定

| ID | DBC | 内容 | 根拠 |
|---|---|---|---|
| 0x21B | `CRZ_INFO.CTS_MODE` (byte5 bit0) | ACC が CTS モードのとき 1 | 18b で CTS と MRCC の区間を全ビット総当たりで比較し、唯一完全に分かれた。186（MRCC のみ）では一度も 1 にならない |
| 0x21B | `CRZ_INFO.CTR1` / `CHKSUM` | byte6 = 4 ビットのカウンタ。byte7 = `(0xFF - sum(byte0..6) + (byte5 & 1)) & 0xFF`（CTS_MODE のビットだけ計算から外れる） | 186 と 18b の異なるメッセージ 11,686 種類すべてで一致 |
| 0x21B | `CRZ_INFO.ACCEL_CMD` | 純正 ACC の加速度指令。約 0.001 m/s²/単位 | 186 で実際の加速度との相関 0.93 |
| 0x09D | `CRZ_BTNS.MRCC_BUTTON` (bit15) / `CTS_BUTTON` (bit11) | MRCC / CTS ボタン。どちらも ACC の ON/OFF を兼ね、MRCC が ON のとき CTS を押すと CTS に切り替わる | 18b の操作手順と一致 |
| 0x09D | （未登録）byte0 bit1 | 実車の CANCEL ボタン（反転ビットは bit18 = DBC 上の `BIT2`）。openpilot が送っている `CAN_OFF`（bit0）とは別 | 18b の CANCEL 操作 |
| 0x228 | `GEAR.MANUAL_MODE` (byte1 bit7) / `AUTO_MODE` (bit5) | 手動変速中（レバー M、または D でパドル操作中）/ 自動変速中。`GEAR` の値は 4 のまま | 186 のパドル操作（111〜127 秒）とレバー M の区間 |
| 0x131 | `NEW_MSG_6.SHIFTER_M` (byte2 bit7) | シフトレバーが M | 186 でレバー M の区間だけ 1、パドル操作のときは 0。0x09E byte1 bit2 も同じ動き |
| 0x078 | `BRAKE.BRAKE_PRESSURE` | 9 ビット（byte3 bit0 が最上位 + byte4）。ペダルを離すと 152 → オフセット −152。単位は不明 | 186 で減速度との相関 0.97 |
| 0x078 | `BRAKE.VEHICLE_ACC_X` | 前後加速度 m/s²（坂の傾きを含む） | 速度の微分、デバイスの IMU と 1:1 |
| 0x078 | `BRAKE.VEHICLE_ACC_Y` | 横加速度。倍率 0.004 m/s²/単位、左が正。イグニッションの ON/OFF 前後は 16.38 で無効値 | デバイス IMU の y 軸との相関 0.94 |
| 0x420 | `CHECK_AND_TEMP.COOLANT_TEMP` | 冷却水温 °C（オフセット −40） | OBD-II PID 0x05 と最大 1 °C 差 |
| 0x202 | `ENGINE_DATA.PEDAL_GAS` | ドライバーのアクセルペダルセンサー。ACC の加速中は 0。最大で 2636 を観測 | OBD のスロットル開度との相関 0.81 |
| 0x202 | `ENGINE_DATA.RPM` | エンジン回転数 | ギア比 × 車輪の回転数と 3% 以内で一致 |
| 0x0FE | `HEARTBEAT_FE` | 100 Hz の生存確認。byte6 の下位 4 ビットがカウンタ、byte7 = `(sum(byte0..6) + 6) & 0xFF` | 2 本で約 38 万フレームすべて一致 |
| 0x47B | `MOVING_STATE` | byte0 bit4 = 停車、bit5 = 走行 | `BSM.STANDSTILL` と 99% 一致 |
| 0x4D9 | `MSG_4D9.CTR` | 3 ビットのカウンタ（byte4 bit0 + byte5 bit7〜6） | 値の並び |
| 0x581 / 0x596 / 0x5A0 | `NM_01` / `NM_16` / `NM_20` | ネットワーク管理の生存確認。`ノード番号 00 aa 55 aa 55 aa 55` | 1 Hz の固定値 |
| 0x454 | `ASCII_ID` | 8 文字の文字列 `0M2P0325` | 固定値 |
| 0x7E0 / 0x7E8 | （登録しない） | 別の OBD 機器の問い合わせと応答。PID 01, 04, 05, 0B〜11, 1F を各 10 Hz | 中身が OBD-II の形式 |

## 🔶 仮説あり

| ID | DBC | 仮説 | 根拠 | 次の確かめ方 |
|---|---|---|---|---|
| 0x4F3 | `MSG_10`（旧 fork の `CTS_ACTIVE`, bit44 など） | 約 60 秒ごとに切り替わる周期的な信号。CTS とは無関係 | 18b で x.5 秒ごとに切り替わり、ACC が OFF でも動く | 長いドライブで周期を測る |
| 0x420 | `CHECK_AND_TEMP.counter_or_GEAR` (byte1) | 走行距離のカウンタ（約 5000 カウント/km） | アイドリングでは増えず、燃料カット中も増える | 距離計の値と比べる |
| 0x420 | `CHECK_AND_TEMP.OUTDOOR_TEMP` (byte7) | 外気温。DBC の式（×0.25 − 63）は合わない。生の値は 186 で 91〜118、18b で 111〜138 | 生の値の範囲 | **メーターの外気温表示をメモ**して式を決める |
| 0x076 | `RPM_RELATED.NEW_SIGNAL_2` | 駆動トルクか、別の前後加速度センサー | 前後加速度との相関 +0.97 | トルクなら空ぶかしでも動くはず |
| 0x130 | `GEAR_RELATED.NEW_SIGNAL_2` | 回転数の帯域か、エンジン負荷の段階（0〜7） | 回転数との相関 +0.96 | 空ぶかしで段階が変わるか |
| 0x0FD | `GAS.GAS_CMD` (byte6) | アクセル開度やトルクの要求値（燃料カット 17 < アイドリング 29 < 加速 78） | 推定した駆動力との相関 0.61 | 空ぶかし、アクセルをいっぱいまで踏む |
| 0x167 | `MORE_GAS` (byte4) | エンジン負荷かトルク | 推定した駆動力との相関 0.81 | 同上 |
| 0x21B / 0x21F | `CRZ_INFO.NEW_SIGNAL_7`, `CRZ_EVENTS.GAS_MAYBE`, `NEW_SIGNAL_21` | ACC の ON / エンゲージ状態のフラグ | ACC ON +1.00 / エンゲージ +0.99 | ACC の状態遷移と並べる |
| 0x21C | `CRZ_CTRL.MSG_1` / `_INV` / `_COPY` | 走行中かどうか（停車判定） | 速度との相関 0.86 | `MOVING_STATE` と並べる |
| 0x050 | `MSG_04.SIGNAL` / `NEW_SIGNAL_1` | 乗員やドアの状態 | シートベルト +0.76、ドア −0.54 | ドアの開閉、シートベルトの着脱、助手席の乗員の有無 |
| 0x425 | `TURN_LAMP_STATUS_MAYBE` | 始動後、各ウインカーを初めて使ったときに立ったままになる。ウインカーの球切れチェックの結果？ | 186 と 18b の両方で、初回のウインカー操作と一致 | ハザードを出したときの変化 |
| 0x4DF | `MSG_4DF.TEMPERATURE_SLOW_MAYBE` (byte5) | 暖まるのが遅い温度（ATF か室内温度） | 走行中ずっと上がり、水温との相関 0.77〜0.96 | **室内温度・外気温をメモ**、エアコンの ON/OFF |
| 0x4DF | `MSG_4DF.NEW_SIGNAL_1` (byte0) | ゆっくり動く値（79〜88、始動直後だけ 0xFE）。電圧か温度 | 値の範囲と動き | ライトやデフォッガーの ON/OFF（電圧なら反応する） |
| 0x4D4 | （未登録） | 走り出してから小さな数（10〜20 前後）がゆっくり増減。燃費の履歴の表示値？ | MAF から計算した燃費とは合わない | トリップのリセット、メーターの表示切り替え |
